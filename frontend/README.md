# Restaurant Full-Stack Website
## Project Overview
This project is a full-stack restaurant website built as part of a web development course. 
This website allows users to:
- View a dynamic restaurant menu
- Make table reservation
- Interact with a responsive, modern UI
An admin can:
- Log in securely
- Add, edit, and delete menu items
## Tech Stack
Frontend
- React
- React Router
- CSS
- JavaScript
Backend
- Node.js (native http module)
- RESTful API
- JWT authentication (for admin)
Database
- MongoDB (via Mongoose)

## Features
Core Features
- Responsive design
- Multi-page SPA using React Router
- Dynamic menu loaded from database
- Client-side form validation
- Menu filtering and search
- Reservation system
- Admin dashboard
- Dark mode
- Authentication and protected routes
- CRUD operations for menu items
